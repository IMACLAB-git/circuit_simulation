# 회로랩 (Circuit Lab)

브라우저에서 도는 실시간 회로 시뮬레이터. [EveryCircuit](https://everycircuit.com/app)처럼
회로를 그리는 즉시 전압이 색으로, 전류가 움직이는 점으로 나타나고, 시뮬레이션이 도는 중에
슬라이더로 소자 값을 바꾸면 회로가 그 자리에서 반응합니다.

서버가 없습니다. 해석기·렌더러·편집기 전부 타입스크립트로 직접 구현했고 브라우저에서만 돕니다.

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # 해석기 정확도 검증 (아래 참고)
npm run build    # dist/ 로 정적 빌드
```

## 배포

백엔드가 없어서 정적 파일만 올리면 끝입니다. 자산 경로는 상대 경로(`base: './'`)라
루트든 하위 폴더든 그대로 돕니다.

```bash
npm run build          # dist/ — 폴더째 웹서버에 복사
npm run build:single   # dist/circuit-lab.html — 파일 하나, 서버도 필요 없음
```

| 상황 | 방법 |
|---|---|
| 실험실 웹서버에 파일을 올릴 수 있음 | `dist/` 내용을 `.../circuit/` 같은 폴더에 복사 → `https://실험실주소/circuit/` |
| 웹사이트가 CMS라 파일 업로드가 안 됨 | GitHub Pages 등에 올리고 링크 또는 `<iframe>`으로 embed |
| 서버가 아예 없음 / 오프라인 실습 | `circuit-lab.html` 한 개만 배포. 공유 드라이브·USB·이메일 첨부 어디서든 더블클릭하면 열림 |

`http://…/circuit/` 하위 경로 배포와 `file://` 단일 파일 실행 모두 콘솔 오류 0으로 확인했습니다.

## 무엇이 되나

- **소자** — 저항, 커패시터, 인덕터, 가변저항, DC/정현파/구형파 전압원, 전류원,
  다이오드, LED, NPN/PNP BJT, N/P채널 MOSFET, 연산증폭기, 스위치, 푸시버튼
- **편집** — 팔레트에서 고르고 클릭해 배치, 핀에서 드래그하면 배선(직각 라우팅),
  드래그로 이동, `R` 회전, 박스 선택, 무한 되돌리기, JSON 저장/열기, localStorage 자동 저장
- **시각화** — 노드 전압을 색으로(파랑↔빨강, 회로 전압폭에 자동 정규화),
  전류를 흐르는 점으로(속도는 로그 스케일이라 µA와 A가 같이 읽힘), LED는 실제 전류만큼 빛남
- **계측** — 최대 8채널 오실로스코프. `Shift`+클릭으로 배선의 전압이나 소자의 전류를 찍습니다.
  세로축은 자동 스케일, 가로축(타임베이스)은 슬라이더로 조절
- **시간** — 속도 슬라이더로 실시간의 10⁻⁷배까지 슬로모션. `⚡ 동작점` 버튼은 충전 과도구간을
  건너뛰고 정상상태로 바로 보냅니다
- **예제 6종** — LED 점멸기(비안정 멀티바이브레이터), RC 저역통과, 직렬 RLC 계단응답,
  반파 정류+평활, 연산증폭기 비반전 증폭기, 이미터 접지 증폭기.
  `#ex=<id>`를 URL에 붙이면 바로 열립니다 (예: `/#ex=rlc`)

## 해석기

`src/engine/` 안에 SPICE와 같은 방식으로 직접 구현했습니다.

**정식화** — 수정 절점 해석(MNA). 미지수는 접지를 뺀 절점 전압과, 전압원·인덕터·연산증폭기
출력의 가지 전류입니다. 조밀 행렬 LU 분해(부분 피보팅)로 풉니다. 선형 회로는 시간 스텝이
고정인 한 행렬이 변하지 않으므로 한 번만 분해하고 우변만 다시 만듭니다.

**시간 적분** — 후진 오일러 동반 모델. 1차 정확도뿐이지만 무조건 안정이라 LC 탱크에서
수치적으로 발진하지 않습니다. 애니메이션 시뮬레이터에서는 이쪽이 훨씬 중요합니다.

**비선형 소자** — Newton-Raphson. 다이오드/LED는 Shockley 식, BJT는 Ebers-Moll 전달 모델,
MOSFET은 Shichman-Hodges 1차 모델, 연산증폭기는 `tanh`로 레일에서 부드럽게 포화하는
전압원입니다. 접합 전압은 SPICE3의 `pnjlim`/`fetlim`으로 제한합니다.

구현하면서 실제로 물린 지점들이 코드 주석에 남아 있습니다. 특히:

- 접합 전압을 제한(limiting)해 놓고 등가 전류를 원래 절점 전압으로 계산하면, 모델을 평가한
  점과 선형화한 점이 어긋나 존재하지 않는 해를 쫓게 됩니다. `stampNL`은 제한된 값으로
  선형화점을 다시 구성합니다.
- `pnjlim`의 역방향 클램프는 매 반복 두 배씩 벌어져야 합니다(`2*vold - 1`). 고정값으로 두면
  역바이어스 다이오드가 영원히 "제한됨" 상태로 남아 스텝이 끝나지 않습니다.
- BJT/MOSFET에 접합 커패시턴스가 없으면 스위칭이 무한히 빠릅니다. 어떤 스텝 크기로도
  Newton이 근처에서 출발할 수 없어 멀티바이브레이터가 뒤집히는 순간에 수렴하지 못합니다.
  실제 소자처럼 pF 단위를 넣으면 해결됩니다.
- 수렴 판정의 절대 허용오차는 회로 자신의 전압폭에 비례해야 합니다. 5 V 회로에서 40 mV에
  앉은 절점을 1 µV까지 고정할 수는 없습니다 — 포화된 트랜지스터의 잔차는 10 µA 언저리에서
  바닥을 치고, 역행렬이 그걸 0.1 mV의 흔들림으로 바꿔 놓습니다.

**튼튼함** — 스텝이 수렴하지 않으면 그 구간을 4등분해 재시도합니다(최대 5단계). 그래도
안 되면 가장 가까웠던 반복해를 채택하고 계속 갑니다. 멀티바이브레이터가 래치되는 순간처럼
어떤 스텝으로도 정확히 풀리지 않는 지점이 실제로 있는데, 한 스텝 때문에 화면 전체를
멈추는 것보다 낫습니다. 이런 스텝의 횟수는 하단 상태바에 `근사 스텝 n회`로 표시됩니다.

### 검증

`npm run check`가 해석기를 해석해(closed form)와 대조합니다. 회로도를 그대로 쓰기 때문에
예제 회로가 깨져도 잡힙니다.

```
저항 분압기            중간 노드 7.5 V, 전류 2.5 mA
RC 계단 응답           t=τ에서 63.2 %, t=5τ에서 정상상태
다이오드               순방향 전압, 전류가 반복 해석해와 0.1 % 이내 일치
NPN 바이어스           Vbe, Ib=(V-Vbe)/R, Ic=β·Ib, 부하선
연산증폭기             이득 1+Rf/Rg = 11배
직렬 RLC               링잉 주파수 vs 1/(2π√LC)
반파 정류              출력 전압, 리플 = I·T/C
RC 저역통과            출력 진폭 vs 1차 필터 이론값
이미터 접지 증폭기      동작점, 이득 ≈ Rc/Re
비안정 멀티바이브레이터  발진 여부, 주기, 비수렴 스텝 비율 < 1 %
DC 동작점              분압 바이어스, 과도해석 정상상태와 일치
```

## 구조

```
src/
  engine/       해석기 — MNA 스탬핑, Newton, 후진 오일러, LU
  model/        소자 라이브러리와 회로도 → 네트리스트 변환
  sim/          실시간 러너 — 프레임 예산, 스코프 버퍼, 전류 애니메이션
  render/       Canvas 심볼과 회로도 렌더링
  ui/           React 편집기 (툴바 / 팔레트 / 캔버스 / 인스펙터 / 스코프)
  dev/          헤드리스 검증 스크립트
```

**연결 규칙** — 두 단자는 같은 격자점을 공유하면 이어집니다. 또 단자가 배선 위 아무 곳에나
놓이면 그 배선과도 이어지므로, T자 분기를 따로 찍지 않아도 됩니다.

**배선 전류** — 배선은 해석기의 미지수가 아닙니다. 각 네트의 배선 그래프에서 신장 트리를
잡고 잎에서 뿌리로 올라가며 소자 핀 전류를 나눠 배분합니다. 어떤 가지의 전류는 그 아래
부분 트리로 들어간 전류의 반대값이라는 KCL이 그대로 답을 줍니다. 트리에 들지 않은
평행 배선에는 전류를 그리지 않는데, 이건 그림에만 영향을 주는 근사입니다.
